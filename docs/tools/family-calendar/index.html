How it works
• Data is stored as a plain JSON file in your own OneDrive app folder (/Apps/Family Calendar/schedule.json).
• You sign in to OneDrive (Microsoft login) to sync — only your account can read or write the file.
• Edit from any device — sign in, add/edit entries, then Save to OneDrive.
• Export downloads a JSON backup; Import loads one back in.

Features
• Weekly grid grouped by day, color-coded per kid
• Add / edit / delete entries with time, activity, location and notes
• Manage people — add or remove family members and their color
• Reminders — while the tab is open, get a notification & beep 15 min before each activity
